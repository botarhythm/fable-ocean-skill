## お返しの、お返し

小さいですが、実地で踏んだものを:

- **Windows 対応パッチ**: `agent_usage.py` の `≈` や `×` は cp932 コンソール（日本語 Windows の既定）で UnicodeEncodeError になり、`--estimate` が落ちます。当方は冒頭に3行の shim（stdout を UTF-8 に再構成）を入れて解決しました。該当コードは当方リポジトリの同ファイル冒頭にあり、突合しやすいようコメントで区切ってあります。Windows の利用者が現れたら、そのまま持っていってください。
- **他環境での動作報告**: 3モードとも Windows + Python 3.13 で動作確認済みです。較正前見積り（±30〜50%）の外側に出る実測が出たら、こちらの記録から報告します。
